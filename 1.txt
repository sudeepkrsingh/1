P3 — Password Cracking
Objective
Use John the Ripper and Hashcat to crack simple password hashes generated in a test

Prerequisites
Kali Linux (both tools are pre-installed)

Step 1: Generate Sample Password Hashes
# Generate an MD5 hash
echo -n "password123" | md5sum
# Output: 482c811da5d5b4bc6d497ffa98491e38
# Generate a SHA1 hash
echo -n "password123" | sha1sum
# Generate a SHA-256 hash
echo -n "password123" | sha256sum
# Create a file with multiple hashes to crack
echo "482c811da5d5b4bc6d497ffa98491e38" > hashes.txt
echo "5f4dcc3b5aa765d61d8327deb882cf99" >> hashes.txt
Step 2: Cracking Hashes with John the Ripper
# Check John the Ripper version
john --version
# Crack using default wordlist
john hashes.txt
# Use the built-in wordlist
john --wordlist=/usr/share/wordlists/rockyou.txt hashes.txt
# Specify hash format explicitly
john --format=raw-md5 --wordlist=/usr/share/wordlists/rockyou.txt 
hashes.txt
# Show cracked passwords
john --show hashes.txt
# Use incremental (brute-force) mode
john --incremental hashes.txt
Note: If 
rockyou.txt
 is compressed, extract it first:
sudo gunzip /usr/share/wordlists/rockyou.txt.gz
Step 3: Cracking Hashes with Hashcat
# Check Hashcat version
hashcat --version
# Identify hash type (example: MD5 = mode 0, SHA1 = 100, SHA256 = 1400)
# Full list: hashcat --help | grep -i md5
# Dictionary attack with MD5 hashes
hashcat -m 0 -a 0 hashes.txt /usr/share/wordlists/rockyou.txt
# Brute-force attack (try all 4–6 character combinations)
hashcat -m 0 -a 3 hashes.txt ?a?a?a?a?a?a
# Show cracked results
hashcat -m 0 hashes.txt --show
# Save results to output file
hashcat -m 0 -a 0 hashes.txt /usr/share/wordlists/rockyou.txt -o 
cracked.txt

P5 — Alternate Data Streams (ADS)
Objective
Understand how ADS works on Windows NTFS, create hidden streams, detect them, and
apply countermeasures. (Performed on a Windows VM from Kali host, or directly on a
Windows VM.)
Note: ADS is a Windows NTFS feature. Perform this on a Windows VM (e.g., Windows
10). You can control the Windows VM via Kali using RDP.
Step 1: Connect to Windows VM from Kali (Optional)
# Install RDP client if needed
sudo apt install remmina -y
# Connect to Windows VM
remmina
# OR
rdesktop 192.168.56.103
Step 2: Create a Normal File (on Windows VM)
Open Command Prompt on the Windows VM:
cd C:\ADSTest
mkdir C:\ADSTest
cd C:\ADSTest
echo This is visible content > normal.txt
type normal.txt
Step 3: Create an Alternate Data Stream
# Hide text inside the ADS
echo This is hidden data > normal.txt:hidden.txt
# The file size of normal.txt appears unchanged
dir normal.txt
# Read the hidden stream
more < normal.txt:hidden.txt
Step 4: Hide an Executable in ADS
# Copy calc.exe into an ADS of a text file
type C:\Windows\System32\calc.exe > normal.txt:calc.exe
# Check: normal.txt still looks like a small text file
dir normal.txt
# Run the hidden executable from ADS
wmic process call create "C:\ADSTest\normal.txt:calc.exe"
Step 5: Detecting ADS (Countermeasures)
# List all streams using dir /r
dir /r C:\ADSTest\
# Use streams.exe (Sysinternals — download on the VM)
streams.exe C:\ADSTest\normal.txt
# Delete all alternate data streams
streams.exe -d C:\ADSTest\normal.txt
From Kali, you can also detect ADS remotely:
# Using Metasploit post-exploitation module
use post/windows/gather/enum_ads
set SESSION 1
run
Step 6: Using Kali to Analyze Windows ADS (via shared folder)

# OR use the ntfs-3g tools
sudo apt install ntfs-3g attr -y
